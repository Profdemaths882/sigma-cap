# Sigma Cap — Vers la réussite

Application d'inscription et de gestion des cours de renforcement (Maths, PC, SVT) · CEM Kennedy · 2026-2027.

- Page publique : tarifs, horaires, équipe, inscription en ligne.
- Espaces élève / parent, prof et gestionnaire (bouton « Mon espace »).
- Les données sont stockées par le serveur Google Apps Script (adresse dans `config.js`).
